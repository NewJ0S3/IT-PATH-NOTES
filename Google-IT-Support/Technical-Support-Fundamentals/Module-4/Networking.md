# Networking

## What is Networking?

### The internet and Networks

The internet is a global network made by linking smaller networks from homes, schools, workplaces, and ISPs. It is a physical infrastructure of computers, cables, satellites, and cellular networks, not just the World Wide Web.

### Clients, Servers, and ISPs

Servers store websites and content, while clients (like phones and laptops) request this content. Clients connect to the internet through Internet Service Providers (ISPs), which manage large networks and connect to other networks.

### Addressing and Data Transmission

Computers have IP addresses (like house addresses) and MAC addresses (unique device identifiers) to route data correctly. Data is sent in small packets that travel through multiple networks and are reassembled at the destination.

### Routing Example

Data packets travel through various intermediate points, each forwarding the packet closer to its destination, similar to how mail is routed through post offices. This process ensures that requests, like accessing a website, reach the correct server and the response returns to the client.

### Network Connection Methods

- Ethernet cables physically connect computers to a network via network ports.
- Wi-Fi provides wireless connectivity using radios and antennas in modern devices.
- Fiber optic cables use glass fibers to transmit data as light, offering higher speeds but at a higher cost.

### Network Devices and Data Routing

- Routers connect multiple devices and route network traffic within and outside local networks.
- Switches act like mail rooms, directing data packets to specific devices within a network.
- Hubs broadcast data to all devices, similar to sending company-wide memos.

### Troubleshooting Network Issues

Understanding network devices and connections is essential for diagnosing internet access problems. Investigations start with the end-user computer and extend to cabling, switches, and routers in the network stack.

### Network Protocols Overview

Network Protocols are sets of rules that guide how data packet are transferred within a network. These protocols ensure packets are routed correctly, not corrupted, secure, and properly addressed.

### Key Protocols: TCP and IP

The Internet Protocol (IP) is responsible for delivering packets to the correct computers using IP addresses. The Transmission Control Protocol (TCP) ensures reliable delivery of information between networks, enabling computers to share data effectively.

### Importance of TCP/IP

TCP/IP has become the predominant protocol suite for the internet. Together, TCP and IP enable the functioning of the internet by routing and reliably delivering data packets.

### Websites and URLs

Websites are text documents formatted with HTML and can include multimedia like text, images, audio, and video. URLs (Uniform Resource Locators) are web addresses that include components like “www” (World Wide Web), domain names (e.g., reddit.com), and domain endings (.com, .org, .edu) indicating the type of website.

### Domain Names and DNS

Domain names are registered through ICANN, ensuring uniqueness. The Domain Name System (DNS) translates human-readable domain names into IP addresses that computers use to locate websites.

### IP Addresses and Internet Navigation

IP addresses identify computers on  the internet; typing an IP address directly can take you to a website. DNS lookups happen every time you visit a website to find the corresponding IP address. Understanding IP addresses and DNS is important for troubleshooting network issues and managing IT infrastructure.

## Limitations of the internet

### IP Address Versions

IPv4 addresses consist of 32 bits divided into four groups, allowing for less than 4.3 billion unique addresses, some of which are reserved for  especial purposes.

IPv6 addresses use 128 bits, vastly increasing the number of possible addresses to an almost unimaginably large number, ensuring enough  addresses for the foreseeable future.

### Challenges and Solutions

The number of device needing IP addresses has exceeded the available IPv4 addresses, prompting  the adoption of IPv6. Adoption of IPv6 has been gradual but is increasing over time.

### Network Address Translation (NAT)

NAT allows organizations to use one public IP address for many private IP addresses within their network. It acts like a receptionist, directing external communications to the correct internal device, reducing the need for multiple public IP addresses. Configuring NAT on routers is a common task for IT supports specialists to enable communication between internal networks and the internet.

## Impact of the internet

### Global Connectivity and Commerce

The internet enables people to connect beyond local neighborhoods, expanding markets from garages sales to global trade. Globalization, driven by the internet and information technology, allows faster communication and increased international business.

### Social Movements and Media Consumption

Social media platforms have globalized social movements, exemplified by the Arab Spring protests gaining worldwide attention. Entertainment consumption has shifted from scheduled TV and physical media to on-demand streaming and digital access.

### Education and Information Access

Online education offers flexible, affordable learning opportunities beyond traditional classrooms. Mobile devices have made accessing vast amounts of information and services more convenient than ever before.

### Understanding Internet of Things (IoT)

IoT refers to connecting more devices to the internet in smarter ways. Examples include smart thermostats, fridges that track food, smartphone-controlled toasters, mood-changing lights, and self-driving cars.

### Implications and Potential of IoT

IoT raises important societal issues such as cybersecurity and personal privacy. It has the potential to transform everyday activities, making manual tasks like making coffee or grocery shopping obsolete.

### Future Outlook

IoT devices will become a significant part of computing in the future. Awareness of IoT  is important even if one does not directly work with these devices now.

### Privacy and Data Sharing

Online activities often require sharing personal information, which can be logged and used for marketing or other purposes. Users should review privacy policies and weigh  the trade-offs of sharing personal data with services.

### Government Regulations and Privacy Protection

Privacy is regulated by laws such as the EU’s data protection regulations and COPPA for children’s online privacy.

These regulations aim to give individuals more control over their personal information and protect vulnerable groups.

### Copyright and Intellectual Property

The internet raises concerns about copyright infringement and intellectual property theft. Solutions include companies and projects that protect creators’ rights and promote open collaboration.

### Computer Security and Cybersecurity Threats

Cybersecurity attacks, like the WannaCry ransomware, have caused significant financial and operational damage. Security is a shared responsibility, and IT support specialists need a fundamental understanding of computer security to protect users and systems.
