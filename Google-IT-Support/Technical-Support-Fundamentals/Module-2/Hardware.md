# Hardware

## The Modern Computer

### Computer Hardware Overview

Computers are everywhere and  fundamentally process, calculate, and store data. Typical desktop setup includes a monitor, keyboard, mouse, and the computer case containing internal components

### Key Internal Components

- The CPU (Central Processing Unit) acts as the brain, handling calculations and data processing.
- RAM (Random Access Memory) serves as short-term memory for temporary data storage during tasks.
- The hard drive provides long-term data storage for files, applications, and media.

### Supporting Hardware and Connectivity

- The motherboard connects all components and allows communication between them, acting like the computer’s circulation system.
- The power supply converts electricity from the wall outlet into usable power for the computer.
- Ports on the computer allow connection of peripherals like monitors, keyboards, mice, and network cables.

### Practical Importance

Understanding computer hardware is essential for IT support roles, aiding in troubleshooting and maintenance. Similar hardware principles apply to laptops and even mobile phones, though in smaller, more integrated forms.

**Ports** are connection points that we can connect devices to that extend the functionality of our computer.

**Motherboard** is the body or circulatory system of the computer that connects all the pieces together.

### Computer Communication and programs

Computers communicate using  binary (1’s and 0’s), which is their machine language. Programs are sets of instructions stored on hard drives, similar to recipes in a cookbook.

### CPU, Memory, and Data Transfer

The CPU acts like a chef who processes instructions; it works faster than it can read recipes, so instructions are copied into RAM (short-term memory) for quick access. Data travels inside the computer via the external data bus (EDB). a set of wires carrying binary signals (voltage on = 1, off = 0).

### Registers, Memory Controller, and Cache

Inside the CPU, registers temporarily store data for processing tasks like addition. The Memory Controller Chip (MCC) acts as a bridge between the CPU and RAM, fetching specific instructions when requested. Cache is a smaller, faster memory than RAM, storing frequently used data to speed up processing, with levels L1, L2 and L3.

### CPU Clock and Performance

The CPU has an internal clock that synchronizes operations through clock cycles, measured in GHz (billions of cycles per second) Overclocking increases the CPU clock speed to improve performance but can cause overheating and other issues.

## Components

### CPU Function and Instruction Set

The CPU acts as a powerful calculator inside the computer, processing binary data. It uses an instruction set, a hard-coded list of simple instructions like adding or copying data, to perform all program functions.

### CPU Manufacturers and Compatibility

Popular CPU manufacturers include Intel, AMD, and Qualcomm, each with different product lines and strengths. CPUs must be compatible with the motherboard, which connects all components, and fit the correct socket type.

### CPU Sockets and Cooling

Two main CPU socket types are Land Grid Array (LGA) with pins on the motherboard and Pin Grid Array (PGA) with pins on the CPU. Proper cooling with a heat sink and fan is essential to prevent CPU overheating.

### CPU Architecture

CPUs come in 32-bit or 64-bit architectures, indicating how much data they can efficiently process. Choosing the right CPU ensures good performance and compatibility with other computer parts.

### RAM Basics

RAM stores data temporarily for quick access by the CPU, and it is volatile, meaning data is lost when power is off. Programs must be  loaded into RAM to run, and the amount of RAM determines how many programs can run simultaneously.

### Types of RAM

- DRAM (Dynamic RAM) stores bits as charged or discharged capacitors on chips.
- DIMM (Dual Inline Memory Module) sticks hold DRAM chips and come in various sizes and pin configurations.

### Advancements in RAM Technology

- SDRAM (Synchronous DRAM) synchronizes with the system clock for faster data processing.
- DDR SDRAM (Double Data Rate SDRAM) is the modern standard with multiple version (DDR1 to DDR5), offering faster speeds, lower power consumption, and higher capacity.

### Compatibility Considerations

RAM must be compatible with the motherboard, including matching the number of pins and supported DDR version. Using faster RAM improves program speed and multitasking capability.

### Motherboard Functions and Chipset

The motherboard routes power from the power supply and enables communication between different computers parts. The chipset, consisting of Northbridge and Southbridge chips, manages data flow between the CPU, RAM, video cards, and input/output devices; modern CPUs may integrate the Northbridge directly.

### Expansion Slots and PCI Express

Expansion slots on the motherboard allow adding functionality, such as upgrading a graphics card. PCI Express (PCIe) is the current standard for expansion buses, providing slot for expansion cards.

### Form Factor and Compatibility

Motherboards come in various sizes called form factors, like ATX and ITX, which determine the number of components and expansion slots they support. Choosing the right form factor is important for building a computer that fits your needs and ensures compatibility with components like RAM and processors.

### Data Size Units

The smallest unit of data storage is a bit, which stores a binary digit (0 or 1). A byte consists of 8 bits and can hold a letter, number, or symbol; larger units include kilobytes (1,024 bytes), megabytes, gigabytes, etc.

### Type of Hard Drivers

- Hard Disk Drives (HDDs) use spinning platters and mechanical arms to read/write data; speed is measure in RPM (revolutions per minute).
- Solis State Drives (SSDs) have no moving parts, store data on microchips, offer faster data access, and are more durable but more expensive than HDDs.

### Hard Drive Interfaces

ATA interfaces, especially Serial ATA (SATA), are common for connecting drives; SATA supports hot swapping and faster data transfer than older interfaces. NVMe is a newer interface designed for hugh-speed SSDs, connecting drives via expansion slots for greater data throughput and efficiency.

### Power Supply Basics

A power supply converts AC (Alternating Current) from the wall outlet into low voltage DC (Direct Current) used by computer components. It includes components like a fan, voltage information label, and cables to connect to motherboard and other parts.

### Electricity Concepts

- Voltage is like water pressure, pushing electricity through circuits; using the wrong voltage can damage devices.
- Current (amperage) is the flow of electricity, measured is amps; higher amps can charge devices faster.
- Wattage is  the product of voltage and current, indicating the total power needed; insufficient wattage can prevent a computer from powering on.

### Practical Considerations

Using the correct voltage and wattage is crucial to avoid damaging devices or poor performance.

Power supplies provide only the power the system requires, so having a higher wattage supply is generally safe. Power supply failure can cause computers not to turn on and may result from burnouts, power surges, or lightning strikes.

Diagnosing and replacing faulty power supplies is an important skill for IT support specialists.

### Mobile Device Characteristics

Mobile devices are portable computers with CPUs, RAM, storage, power systems, and peripherals, often powered by batteries. They can be general-purpose devices like smartphones and tablets or specialized devices like fitness trackers and e-readers.

### Integration and Components

Mobile devices tend to have highly integrated components, often soldered onto the motherboard. Small devices use a system on a chip (SoC) that combines CPU, RAM, and sometimes storage to save space and power.

### Peripherals and Connectivity

Mobile devices use peripherals such as Bluetooth headphones and can themselves act as peripherals. The may use standard or proprietary ports and connectors, sometimes designed for specific needs like waterproogfing.

### Operating System and Support

Mobile devices run OS and Apps optimized for their size and power constraints. IT support specialists may assist with setup, troubleshooting, and repair, while respecting user privacy, especially in Bring Your Own Device (BYOD) scenarios.

### Rechargeable Battery Basics

Mobile devices use rechargeable batteries to provide power on the go, which can be charged via external chargers, cradle stands, or wireless inductive charging pads. Rechargeable batteries have a limited lifespan measured in charge cycles, and their performance declines as the age, affecting charge time and capacity.

### Charging and Power Management

Charging requires an external power source and a charging circuit that converts input power to the correct output for the battery. Using the correct charger for each device is crucial  to avoid damage to the battery, device, or charger.

### Battery Safety and Maintenance

Batteries should be charged and discharged within safe temperature ranges to prevent damage or dangerous situations like swelling or fire. When batteries reach the end of their life, they may need replacement; some devices slow down to extend battery life, and battery replacement can vary in difficulty depending on the device.

### IT Support Considerations

IT support specialists may be trained to replace batteries or manage device repairs and should verify compatibility between chargers, batteries, and devices. Educating end-users on best practices for battery care and troubleshooting charging issues is an important part of IT support.

### USB Peripherals and Standards

Peripherals are external devices connected to a computer to add functionality, such as a mouse, keyboard, or monitor.

- USB  (Universal Serial Bus) is the most common connection type, with versions like USB 2.0, 3.0, and 3.1 differing in transfer speeds measured in megabits per second (Mb/s).
- USB ports are backward compatible, meaning older devices can work with newer ports but at the older device’s speed.
- USB ports are color-coded: USB 2.0 is usually black, USB 3.0 blue, and USB 3.1 teal, though this can vary by manufacturer.

The latest USB connector type is USB Type C, which supports data transfer, display,  and power delivery.

### Display Peripherals and Connections

Common display connections include DVI, HDMI, and Display port.

- DVI generally supports video only, while HDMI and DisplayPort support both video and audio.
- USB Type C can also handle display output along with data and power, making it a versatile connection standard.

### Practical IT Support Knowledge

As an IT support specialist, understanding these peripheral types and their compatibility is essential for troubleshooting and setting up computer systems.
