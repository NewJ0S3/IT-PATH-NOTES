# Communication in a Connected World

## Network Types

A computer network is a group of interconnected devices that communicate and share information, resources and services.

Networks vary in size, depending on the number of connected devices and the geographical area they cover.

## Main Network Types (by size)

| Network Type | Description |
| --- | --- |
| Small Home Network | Connects a few devices at home to each other and the Internet. |
| SOHO Network | Small Office/Home Office. Connects devices in small businesses or remote offices to shared resources and corporate networks. |
| Medium to Large Network | Used by organizations, schools and companies with hundreds or thousands of connected devices. |
| Worldwide Network | Connects networks across the world. The Internet is the best example. |

## The internet

- The internet is a global network of interconnected public and private networks.
- It allows devices worldwide to exchange information using common standards.
- It is not owned or controlled by a single individual or organization.
- It is often described as a network of networks.

**Key Concept:** Networks allow devices to communicate, share resources and access information regardless of their location.

## Data Transmission

Data transmission is the process of transferring information between devices through a netwok.

## Types of Personal Data

Personal data can be classified into three categories:

- **Volunteered Data:** Information that individuals deliberately share, such as social media posts, photos and profile information.
- **Observed Data:** Information collected by monitoring people’s activities, such as location data from smartphone.
- **Inferred Data:** Information obtained by analyzing volunteered or observed data, such as a credit score.

## Bits and Bytes

Computers process and store information using the binary system, which consist of two values: 0 and 1.

- **Bit (Binary Digit):** The smallest unit of digital information. It can have a value of either 0 or 1.
- **Byte:** A group of 8 bits.
- **ASCII (American Standard Code for Information Interchange):** A character encoding standard that represents characters using binary values. In standard ASCII, each character uses 8 bits.

Examples:

- A = 01000001
- 9 = 00111001

Almost all digital information, including text, images, audio and video, is represented using binary data.

## Common Methods of Data Transmission

Before data can travel through a network, it must be converted into signals.

**Network Media:** The physical medium through which signals travel from a source device to a destination device.

The are three common transmission methods:

- Electrical Signals: Data is transmitted as electrical pulses through copper cables. Common in Ethernet connections.
- Optical Signals: Electrical signals are converted into light pulses that travel through fiber-optic cables.
- Wireless Signals: Data is transmitted using electromagnetic waves, including radio waves, microwaves and infrared signals. Wi-Fi is a common example.

A signal can be converted between different transmission methods as it travels across a network.

## Bandwidth and Throughput

Bandwidth and throughput describe the capacity and actual data transfer performance of a network connection.

### Bandwidth

Is the maximum theoretical capacity of a network medium to carry data over a given period of time.

Digital bandwidth measures how many bits can theoretically be transmitted per second.

### Common Units of Measurement

| Unit | Abbreviation | Equivalent |
| --- | --- | --- |
| Bits per second | bps | 1 bit/second |
| Kilobits per second | kbps | 1,000 bps |
| Megabits per second | Mbps | 1,000,000 bps |
| Gigabits per second | Gbps | 1,000,000,000 bps |
| Terabits per second | Tbps | 1,000,000,000,000 bps |

Bandwidth depends on several factors, including:

- Physical characteristics of the transmission medium.
- Network technologies being used.
- Signal transmission capabilities.

## Throughput

Is the actual rate at which data is successfully transferred across a network over a given period of time.

Is usually lower than the specified bandwidth because of network conditions and other limitations.

Factors affecting throughput include:

- Amount of data being transmitted.
- Types of data being transmitted.
- Network congestion and traffic.
- Latency caused by network devices between the source and destination.

## Latency

Is the time required for  data to travel from one  point to another, including any delays along the way.

Lower latency generally means faster responses and is particularly importan for online gaming, video calls and real-time applications.

## Bandwidth vs. Throughput vs. Latency

| Concept | Meaning |
| --- | --- |
| Bandwidth | Maximum theoretical data transmission capacity. |
| Throughput | Actual data transfer rate achieved. |
| Latency | Time it takes for data to travel between two points. |

**Example:**

Imagine you have a 100 Mbps Internet connection:

- Bandwidth: 100 Mbps (theoretical capacity).
- Throughput: 75 Mbps (actual transfer rate).
- Latency: 20 ms (time delay).

The throughput is lower than the bandwidth because network conditions can affect actual performance.

**Importan:** In a network path containing multiple connections, the slowest link can become the bottleneck and limit the maximum achievable throughput.

## Key Takeaways

- Networks connect devices to exchange information and share resources.
- The internet is a worldwide network of interconnected networks.
- Computers process information using binary digits (0 and 1).
- A byte consists of 8  bits.
- Network data travels through electrical, optical or wireless signals.
- Bandwidth represents theoretical network capacity.
- Throughput represents actual data transfer performance.
- Latency measures the delay involved in transmitting data.
