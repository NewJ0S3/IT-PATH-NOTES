# Wireless and Mobile Networks

## 1. Wireless Networks

A **wireless network** allows devices to communicate and exchange data without using physical cables. Instead, it uses electromagnetic waves, primarily radio waves, to transmit information.

Wireless networks provide mobility, flexibility and easier network deployment.

### 1.1 Wireless Local Area Networks (WLAN)

A **Wireless Local Area Network (WLAN)** connects devices within a limited geographical area using wireless communication.

WLANs are commonly used in:

- Homes.
- Offices.
- Schools and universities.
- Public spaces.

**Wi-Fi** is the most common technology used to implement WLANs. It is based on the IEEE 802.11 family of standards.

### 1.2 Wireless Network Components

The main components of a wireless network include:

| Component | Function |
| --- | --- |
| Wireless Access Point (AP) | Provides wireless connectivity and connects wireless devices to a wired network. |
| Wireless Network Interface Card (NIC) | Allows a device to communicate over a wireless network. |
| Wireless Router | Combines routing and wireless access point functionality, often including a switch and firewall. |
| Antenna | Transmits and receives radio frequency signals. |

### 1.3 Wi-Fi Standards

Wi-Fi operates according to IEEE 802.11 standards. Different standards provide different speeds, frequency bands and capabilities.

| Standard | Wi-Fi Generation | Frequency Bands |
| --- | --- | --- |
| 802.11n | Wi-Fi 4 | 2.4 GHz and 5 GHz |
| 802.11ac | Wi-Fi 5 | 5 GHz |
| 802.11ax | Wi-Fi 6 / Wi-Fi 6E | 2.4 GHz, 5 GHz and 6 GHz (Wi-Fi 6E) |
| 802.11be | Wi-Fi 7 | 2.4 GHz, 5 GHz and 6 GHz |

**Note:** Wi-Fi 6E extends Wi-Fi 6 operation into the 6 GHz band. Wi-Fi 7 introduces additional improvements in speed, capacity and latency.

### 1.4 Wireless Frequency Bands

Wi-Fi networks commonly operate on three frequency bands:

2.4 GHz

- Longer range.
- Better ability to penetrate walls and obstacles.
- More susceptible to interference.
- Usually offers fewer non-overlapping channels.

5 GHz

- Higher potential speeds.
- More available channels.
- Less interference from common household devices.
- Shorter range than 2.4 GHz.

6 GHz

- Additional spectrum and more available channels.
- Supports newer Wi-Fi technologies.
- Less congestion in compatible environments.
- Requires compatible devices and access points.
- Generally has shorter range and poorer obstacle penetration than lower frequencies.

### 1.5 SSID and Wireless Channels

**SSID (Service Set Identifier):** The name used to identify a wireless network. It is the name users see when searching for available Wi-Fi networks.

**Wireless Channel:** A specific portion of the radio frequency spectrum used by a wireless network to communicate.

Important considerations:

- Multiple nearby networks using overlapping channels can cause interference.
- Selecting an appropriate channel can improve wireless performance.
- The 2.4 GHz band is particularly susceptible to interference from neighboring networks and other devices.

### 1.6 Wireless Network Security

Wireless networks require security mechanisms to prevent unauthorized access and protect transmitted data.

**Common Wi-Fi Security Protocols:**

| Protocol | Description |
| --- | --- |
| WEP | An outdated and insecure encryption protocol. |
| WPA | Introduced as an improvement over WEP, but now obsolete. |
| WPA2 | Uses AES-based encryption through CCMP in its standard implementation. Widely supported. |
| WPA3 | Provides stronger security and improved authentication compared with WPA2. |

**Best Practices for Wireless Security:**

- Use WPA2-AES or WPA3 whenever possible.
- Create strong and unique Wi-Fi passwords.
- Change default router administrator credentials.
- Keep router firmware updated.
- Disable WPS if it is not needed.
- Avoid using open wireless networks for sensitive activities.

**Key Concept:** WPA3 is the preferred modern Wi-Fi security standard when supported by all relevant devices.

## 2. Mobile Device Connectivity

Mobile devices use several wireless technologies to communicate, exchange information and access network services.

Common examples include:

- Smartphones.
- Tablets.
- Laptops.
- Smartwatches.
- Wireless headphones.
- IoT devices.

### 2.1 Cellular Networks

**Cellular Networks** provide wireless communication over large geographical areas using a system of interconnected cells.

Each cell is served by a cellular base station, commonly called a cell tower.

Mobile devices communicate with these base stations to access voice, messaging and Internet services.

**Main Cellular Generations:**

| Generation | Technology | Main Characteristics |
| --- | --- | --- |
| 2G | GSM, CDMA | Digital voice calls and SMS messaging. |
| 3G | UMTS, CDMA2000 | Mobile Internet and improved data services. |
| 4G | LTE | High-speed mobile broadband and improved multimedia services. |
| 5G | 5G NR | Higher potential speeds, lower latency and increased network capacity. |

**Important Concepts:**

- **SIM (Subscriber Identity Module):** Identifies and authenticates a subscriber on a mobile network.
- **eSIM:** An embedded digital SIM that allows compatible devices to activate cellular plans without a physical SIM card.
- **Roaming:** Allows a mobile device to use another operator's network when outside its home network's coverage area, subject to agreements and plan conditions.
- **Mobile Data:** Internet connectivity provided through a cellular network.

### 2.2 Bluetooth

**Bluetooth** is a short-range wireless technology used to connect devices and exchange information without requiring cables.

Common applications include:

- Wireless headphones and speakers.
- Keyboards and mice.
- Smartwatches.
- File transfers.
- Connecting peripherals to computers and smartphones.

**Bluetooth Characteristics:**

- Operates mainly in the 2.4 GHz ISM frequency band.
- Uses short-range radio communication.
- Requires compatible devices.
- Supports different power and range profiles.

**Bluetooth Pairing:** The process of establishing a trusted connection between two Bluetooth devices.

Example: Pairing wireless headphones with a smartphone.

### 2.3 NFC (Near Field Communication)

**NFC** is a short-range wireless communication technology that allows compatible devices to exchange small amounts of information when placed very close together.

Common applications include:

- Contactless payments.
- Access cards and identification.
- Public transportation systems.
- Quick device pairing.
- Reading NFC tags.

NFC operates at 13.56 MHz and typically works over distances of only a few centimeters.

### 2.4 Mobile Hotspots and Tethering

**Mobile Hotspot:** A feature that allows a smartphone or dedicated mobile device to share its cellular Internet connection with other devices through Wi-Fi.

**Tethering:** The process of sharing a mobile device's Internet connection with another device.

Common tethering methods:

- Wi-Fi tethering: Shares the connection wirelessly.
- USB tethering: Shares the connection through a USB cable.
- Bluetooth tethering: Shares the connection through Bluetooth.

**Example:** If your laptop has no Internet connection, you can enable your smartphone's mobile hotspot and connect the laptop to it.

### 2.5 GPS (Global Positioning System)

**GPS** is a satellite-based navigation system that allows compatible devices to determine their geographical position.

It is commonly used for:

- Navigation and maps.
- Location tracking.
- Geolocation services.
- Fitness and activity tracking.

GPS is primarily a positioning and navigation technology, not an Internet connectivity method. A device can determine its GPS position without having an active mobile data connection.

## 3. Comparison of Wireless Technologies

Different wireless technologies are designed for different purposes.

| Technology | Main Purpose | Typical Range |
| --- | --- | --- |
| Wi-Fi | Local network and Internet access. | Room to building, depending on conditions. |
| Bluetooth | Connecting nearby peripherals. | Usually a few to tens of meters. |
| NFC | Very short-range communication and payments. | A few centimeters. |
| Cellular (4G/5G) | Wide-area mobile connectivity. | Several kilometers per cell, depending on deployment. |
| GPS | Positioning and navigation. | Satellite coverage; requires suitable satellite reception. |

**Important:** Wi-Fi, Bluetooth, NFC, cellular and GPS are different technologies. They are not interchangeable because they serve different purposes.

## Key Takeaways

1. Wireless networks transmit data using electromagnetic waves instead of physical cables.
2. WLANs connect devices within a limited geographical area.
3. Wi-Fi is based on the IEEE 802.11 family of standards.
4. SSID identifies a wireless network, while channels determine where it operates within a frequency band.
5. The 2.4 GHz band offers better range, while 5 GHz and 6 GHz provide additional capacity and higher potential speeds.
6. WPA2 and WPA3 provide wireless network security; WEP and WPA are outdated.
7. Cellular networks use interconnected cells and base stations to provide mobile connectivity.
8. Bluetooth connects nearby devices and peripherals.
9. NFC enables very short-range communication, commonly used for contactless payments.
10. Mobile hotspots and tethering allow smartphones to share their Internet connections.
11. GPS provides positioning and navigation without requiring an Internet connection.

**Remember:**

- Wi-Fi = Wireless LAN connectivity.
- SSID = Wireless network name.
- WPA2/WPA3 = Wi-Fi security.
- Bluetooth = Short-range device connectivity.
- NFC = Very short-range communication.
- Cellular = Wide-area mobile connectivity.
- GPS = Positioning and navigation.
- Hotspot = Sharing a mobile Internet connection.
