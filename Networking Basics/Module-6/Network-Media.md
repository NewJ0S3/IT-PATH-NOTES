# Module 6: Network Media

## 1. Network Media Types

**Network Media** refers to the physical or wireless channels through which data travels from a source device to a destination device.

Network media provides the transmission path that allows network devices to communicate.

Modern networks primarily use three types of media:

1. Metal wires within cables (Copper).
2. Glass or plastic fibers within cables (Fiber Optic).
3. Wireless transmission.

### 1.1 Copper Media

Copper cables transmit data using electrical impulses.

They are commonly used in Ethernet networks and other wired communication systems.

**Main Types of Copper Cables:**

A.Twisted-Pair Cable

Twisted-pair cable consists of pairs of insulated copper wires twisted together to reduce electromagnetic interference (EMI) and crosstalk.

Each pair contains two wires twisted around each other to help prevent signal degradation.

There are two main types:

- **UTP (Unshielded Twisted Pair):** Does not have additional metallic shielding. It is widely used in Ethernet networks because it is affordable and easy to install.
- **STP (Shielded Twisted Pair):** Includes additional shielding to provide greater protection against electromagnetic interference.

**Characteristics:**

- Commonly used for Ethernet connections.
- Uses electrical signals.
- Generally inexpensive and easy to install.
- Can be affected by electromagnetic interference.
- Twisting the wires helps reduce interference.

B.Coaxial Cable

Coaxial cable is a copper cable consisting of a central conductor surrounded by insulation, metallic shielding and an external protective jacket.

**Characteristics:**

- Uses electrical signals to transmit data.
- Provides shielding against external interference.
- Commonly used for cable television and cable Internet connections.
- Can also be used in satellite communication systems.

### 1.2 Fiber-Optic Media

Fiber-optic cables transmit data using pulses of light instead of electrical signals.

They contain extremely thin strands of glass or plastic fibers that carry digital information over long distances.

**Characteristics:**

- Supports very high bandwidth.
- Suitable for long-distance transmission.
- Not affected by electromagnetic interference (EMI).
- Uses light signals instead of electrical impulses.
- Generally more expensive to install than traditional copper cabling.

**Applications:**

- Internet backbone connections.
- ISP infrastructure.
- Data centers.
- Connections between buildings.
- High-speed telecommunications networks.

**Important:** Because fiber-optic cables use light rather than electrical signals, electromagnetic interference does not affect their data transmission.

### 1.3 Wireless Media

Wireless media transmits data without physical cables.

Information is encoded through the modulation of specific frequencies of electromagnetic waves.

Common wireless technologies include:

- Wi-Fi.
- Bluetooth.
- Cellular networks.
- Satellite communication.

**Characteristics:**

- Does not require physical cabling between communicating devices.
- Provides mobility and flexibility.
- Can cover different geographical areas depending on the technology.
- Can be affected by interference, physical obstacles and environmental conditions.
- Requires appropriate wireless security mechanisms.

**Examples:**

- Wi-Fi connecting a laptop to a home router.
- Bluetooth connecting wireless headphones to a smartphone.
- Cellular networks providing Internet access to mobile devices.

## 2. Comparing Network Media

Each network media type has different characteristics, advantages and limitations.

| Media Type | Transmission Method | Main Advantages | Main Limitations |
| --- | --- | --- | --- |
| Copper | Electrical impulses | Affordable, easy to install and widely available. | Susceptible to interference and distance limitations. |
| Fiber Optic | Pulses of light | High bandwidth, long distances and immunity to EMI. | Higher installation costs and more specialized handling. |
| Wireless | Electromagnetic waves | Mobility, flexibility and no physical cabling. | Interference, obstacles and security considerations. |

### 2.1 Criteria for Selecting Network Media

When selecting network media for a network installation, four main criteria should be considered:

1.Distance

What is the maximum distance over which the media can successfully carry a signal?

Different media types support different transmission distances.

2.Environment

Where will the media be installed?

Consider factors such as:

- Electrical interference.
- Physical obstacles.
- Temperature and environmental conditions.
- Indoor or outdoor installation.

3.Amount of Data and Transmission Speed

How much information needs to be transmitted, and at what speed?

Networks requiring high bandwidth may benefit from fiber-optic connections.

4.Cost

What is the cost of the media and its installation?

Consider:

- Cable and equipment costs.
- Installation expenses.
- Maintenance requirements.
- Specialized tools and infrastructure.

## Key Takeaways

1. Network media provides the channel through which data travels between devices.
2. Modern networks primarily use copper cables, fiber-optic cables and wireless transmission.
3. Copper media transmits data using electrical impulses.
4. Twisted-pair cables are commonly used by Ethernet technology.
5. UTP has no additional metallic shielding, while STP includes shielding against interference.
6. Coaxial cable contains a central copper conductor, insulation, metallic shielding and a protective jacket.
7. Fiber-optic cables use glass or plastic fibers to transmit pulses of light.
8. Fiber-optic transmission supports high bandwidth and long distances and is immune to electromagnetic interference.
9. Wireless media transmits data through modulated electromagnetic waves.
10. Media selection depends on distance, environment, transmission requirements and installation cost.

**Remember:**

- Copper = Electrical impulses.
- Fiber Optic = Pulses of light.
- Wireless = Electromagnetic waves.
- UTP = Unshielded Twisted Pair.
- STP = Shielded Twisted Pair.
- Coaxial = Central conductor + insulation + shielding.
- EMI = Electromagnetic Interference.
- Ethernet = Commonly uses twisted-pair copper cables.
